选例先按地理位置固定：保留网站第一例，再取原固定十二例中最西侧及最北侧起点，得到原案例1、2、9。用户要求检查西南部分后，新增第四例：在R内经度小于−77°、纬度小于32.75°的保存开发预测中，选取距该地理子框中心79°W、31.375°N最近的真实起点。该点为78.978198°W、31.355691°N，距参照点约2.98 km，保存索引12820，不属于原十二例。两次地理规则均在读取对应评分和分布形状前记入[W12审计](../../records/W12_AUDIT.md)。

脚本读取保存的22个高斯成分权重、均值和协方差，用混合分布公式直接生成显示栅格。没有模型推理、抽样、拟合、新评分或最终测试访问。原参数、坐标和评分表的SHA256均与网站来源及实验manifest匹配；R、D和岸线也按资产登记值核对。精确案例键与原始数值保存在[provenance.json](provenance.json)。

颜色表示**模型位移平面概率密度（km⁻²）**：在每个起点的东、北向测地位移平面求密度，再映射到经纬度。它不是每个显示格的概率，也不是经过地表面积雅可比校正的地理面积密度。显示栅格只用于画图，不决定模型分辨率，不用于区域概率积分。四图同范围、同色标，近岸另加局部放大图。

90%边界直接使用保存的评分椭圆，经原Lambert Azimuthal Equal-Area投影（中心75°W、35°N）逆变换到WGS84；不重新估计椭圆，不将它改称最高密度边界。起终点来自对应预测键及原开发验证配对。GSHHG 2.3.7海陆边界采用登记的intermediate分辨率。

视窗为81.5°–68.5°W、28°–39°N，尾部密度低于10⁻⁸的部分留白，视窗外不显示。参数及完整概率权重保持不变，陆地密度照常画出。此图未重新计算视窗内概率，不能将图中颜色积分当成完整概率总量。表12及正文的区域面积、覆盖状态与陆地概率全部复制自保存的评分结果。

实际查看PNG后核对：四图标题、坐标、共享色标、起终点、R/D说明与90%区域可辨识；近岸放大图不遮挡主要概率区域，面积标签与刻度分开。西南例呈向东北延伸的长条状分布，实际终点位于保存椭圆内。科学解释及后续区域分析缺口见[W12正文](../../drafts/W12_prediction_cases_and_regional_distribution.md)。
