# Sources and visual semantics

- Three.js 0.181.1, MIT: https://github.com/mrdoob/three.js/tree/r181 . Local library and license included. Water/Sky addons and waternormals.jpg from this version. Water material is extended in ocean.js with an analytic geometric wave field shared by the buoy pose.
- Natural Earth 1:50m land polygons: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_50m_land.geojson . Public domain: https://www.naturalearthdata.com/about/terms-of-use/ . Clipped to the regional display envelope; geographic context, not the modelling land mask.
- release_R.geojson copied unchanged from the project's configs/assets.json release_R asset: archive/data_before_release_20261016/reference/acquisition/geometry/release_R.geojson. SHA recorded in geography.json.
- Waves, illumination, buoy design, local drift and scale transition are illustrative. The marked map origin at 77 W, 32 N is a synthetic point within R; it is not a selected observational ID or model prediction. The geometric R overlay is the authentic project release boundary.
- No trained model, drifter observations, prediction products, personal credentials, or restricted test data are included.
