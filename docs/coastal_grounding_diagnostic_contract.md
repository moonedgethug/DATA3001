## 3. 搁浅证据：标签与时间分开

### 3.1 ID 层的官方标记

保留原生与已核验目录两套值、来源日期和冲突列，不能只保留合并后的单一代码。

| 官方代码 | 报告标签 | 使用限制 |
|---|---|---|
| 1 | 官方记录为最终搁浅 | 不是所有小时都已搁浅，也不是已确认的七天内事件 |
| 2 | 被船拾取 | 单列为回收，不归入搁浅 |
| 3 / 4 | 停止发报 / 发报异常 | 原因不明，不归为“未搁浅” |
| 5 / 6 | 电池问题 / 停用 | 保留官方类别，不据此证明期间从未搁浅 |
| 0 | 来源快照时仍存活 | 不解释为终生未搁浅；使用已有后续目录时记录来源差异 |
| 缺失或冲突 | 未解决 | 不自动补值或多数表决 |

汇总按训练/验证分别列出 ID 数量、占各自 ID 总数比例及涉及已使用配对数。后者反映样本暴露，不是独立事件数。

### 3.2 轨迹筛查及人工复核

官方标记是主要证据，末段轨迹用于补充和识别冲突；不开发自动分类模型。

- 所有 383 个 ID 完成元数据与时间/地理关联检查。只对官方 code 1、来源冲突，以及未知终止但靠岸的记录进行详细末段筛查。
- 靠岸筛查阈值为终止坐标距岸线 **≤5 km**。这是本项目宽松排查阈值，不是物理搁浅定义；远岸的官方 code 1 仍保留，浅滩搁浅不能仅靠岸距排除。
- 读取已有末段 **终止边界前 14 天、后 7 天**的记录（若存在）。后边界记录仅作事件证据，不恢复为训练样本。
- 位置停滞提示：最后 168 小时首末净位移 <1 km；窗口两端时刻均有合格位置，169 个小时格点至少有 136 个、最长缺口 ≤6 小时，才计算该提示。同时报告窗口轨迹半径与累计移动，避免把绕圈后返回误认为静止。缺失者记“无法检查”。不自动把该提示升级为搁浅。
- 7 天/1 km 的思路参考历史 DAC 筛查；覆盖率、5 km 岸距和复核安排是本轮自定规则。小时插值点不是独立 GPS 定位，不能把连续小位移看作独立多次证据。
- 原生 error 已知存在尺度问题，**不使用未修复 error 作判断阈值**；只引用已有修复覆盖的记录。无可靠定位误差时保留不确定，不新增误差修复。
- 人工逐例核查最多 **12 个 ID**：官方搁浅、疑似近岸终止、来源/几何矛盾三类各最多 4 个。类内优先与研究七天窗口相关，再按 ID 升序；三类顺序去重，不看模型得分挑案例。超过额度的候选仍列全表并标明“未人工复核”。

复核输出使用两列：`official_status` 和 `evidence_grade`。证据等级为“官方且轨迹相容／仅有官方标记／疑似、未证实／来源矛盾／证据不足”。没有官方标记时，靠岸和停滞至多支持“疑似”；不据此产生训练标签，也不报告分类准确率。

### 3.3 七天时间关联

`end_date` 只作最后有效时间背景。仅当末段确实能辨认“最后一次仍在漂流”与“首次持续停留”时，另记事件可能区间 `(L,U]`，保存依据；不以最后有效时刻代替 L 或 U。

对每个起点窗口 `(t0,t0+7d]` 分为：事件区间完全位于窗口内／可能重叠／不重叠／事件时间未知。对只有官方最终搁浅标记的 ID，只报告“最后有效时间落在窗口内”，不能写成“已证实七天内搁浅”。

事件地点另分 R 内、D 内但 R 外、D 外、未知；域外的最终搁浅不能自动解释域内预测。释放时并不知道的终止标签只用于事后诊断，不进入任何预测接口。

## 4. 七天配对缺失：先固定分母，再看原因

### 4.1 两个账本

**已使用账本：** 冻结的 265,393 + 33,971 条七天配对，按键逐项对账，不新增/删除。确认原资格、训练/验证角色及其完整窗口。

**候选起点账本：** 从上述 383 个 ID 已保存的 `release_labels` 读取所有七天候选起点，包括 reason 非零的行。训练 ID 仅取 2001–2019 起点，验证 ID 仅取 2020–2022 起点；保留原 R 内起点与资格定义。通过现有 canonical/qualification 来源只读检查起点目录是否完整；若发现账本没有覆盖可重建的候选起点，不擅自扩充样本，暂停该分母统计并报告。

必须先对账“候选 → 原资格及角色排除 → 已使用”的键集合与数量。不能直接从已使用配对寻找缺失，也不能在本轮按更严格岸线或官方分钟时间重判原资格。

### 4.2 原因分类

保留原 `reason_code` 和全部 `secondary_predicates`。原 reason 的优先级可能掩盖同时存在的终止/路径缺口，所以同时提供互斥主原因表与可重叠原因标记表，后者不得相加为总数。

分别列出：

1. 已进入冻结研究的有效配对。
2. 时间窗口、训练标签跨界、whole-ID 隔离等行政/角色排除。
3. 观测轨迹在目标时刻之前终止。
4. 目标时间戳缺失或目标位置质量不合格。
5. 路径缺口、几何不确定、状态资格或其他原规则排除。
6. 原规则识别的已知退出 E（若候选中存在）；保留其独立语义，不当作“缺失落点”或“搁浅”。

原 `track_termination` 的实现表示目标时间超过保留轨迹末时刻，不能单凭它证明仪器发生物理终止。另设 `termination_evidence`：已知终止／来源截止或当时仍存活／未解决；并列保留 canonical 末时刻、官方结束时刻和来源行政截止。原始原因不改写，未解决者不算作已知搁浅或故障。

“模型未使用”与“七天终点缺失”分成两列：有七天位置但路径/资格不合格，不算位置缺失；因明确退出已提前结束原目标，也不要求把其第七天坐标补进来。可用位置还需同时展示原资格与官方时间冲突情况，不把数据文件中存在一个数值等同有效海上观测。

历史验证窗口按保存的起点/观测资格规则复用，不私自新增“终点必须在 2023-01-01 前”的条件。训练标签边界则严格复用现有 `required_interval_end_epoch < 2020-01-01` 规则。源数据行政截止沿用历史来源，不用当天日期替代。

### 4.3 缺失与搁浅关联

重点交叉表：观测终止/七天落点不可用 × 官方原因 × 起点近岸组 × 训练/验证。标出 code 1 且最后有效时间处于七天窗口的候选，称为“搁浅标记相关的观测终止”，不直接认定因果。

统计同时给出候选数、缺失数、独立 ID 数、配对比例和 ID 等权比例。ID 等权定义为：先在每个 ID 的相同合格候选分母内算缺失比例，再对有该分母的 ID 平均。分母为零的 ID 单列，不能当作零缺失。

明确主要缺失率：令 A 为上述角色窗口内的原七天候选；I 为原起点不合格；C 为原行政不成熟、标签跨界或角色排除；E 为原已确认退出。分母集合 `N = A \\ (I ∪ C ∪ E)`；分子为 N 中第七天原资格下有效位置不可用的起点。路径不合格但第七天有效位置存在的记录仍在 N 中，其缺失分子为零，同时保留“配对未使用”标记。

C 必须结合原 `secondary_predicates` 的行政 bit 2、原来源截止和 `required_interval_end_epoch` 判定，不能只检查 `reason_code == 2`；原 stopped 原因优先级可能把同时存在的行政不成熟藏在路径/几何原因之后。明确退出仍按原规则单列。完整候选流程全部保留，互斥流程表按原主原因计数，N 的筛选另列布尔标记，不用一张优先级表替代两种统计。

全体物理终止的影响不能由这 383 个已入选 ID 推断，也无法为缺失的真实终点计算 ES 或命中率。

## 5. 近岸预测表现：只汇总冻结评分

### 5.1 固定分组

主要分组只使用**真实出发点**到岸线的距离，避免用未来终点决定主要评价分组：

- 近岸：海洋侧距离 ≤50 km；离岸：>50 km。
- 预先固定细分：≤10 km、(10,50] km、>50 km。阈值是描述性分组，不代表统一海岸动力边界，不看结果后调整。
- 几何判为陆地、坐标缺失、距离无法计算的起点单列；仍纳入全局原评分，不能默默排除。
- 实际终点岸距、官方终止类别仅作明确标注的事后解释表。

岸线采用已缓存 GSHHG high 的真实边界；先取 boundary 再作区域裁切，不能把裁切框边缘当海岸。采用现有 `LAEA(lat_0=35, lon_0=-75, WGS84)` 的投影距离并标明其近似性质；距离以 km 表示，不能直接用经纬度的欧氏距离。

执行前对 200 个固定、与模型分数无关的空间检查点作 WGS84 测地岸距独立核查；岸线仅在需要的局部加密至 ≤100 m，不全全球加密。阈值复核带必须覆盖区域投影误差上界与岸线离散误差之和，并且至少为 5/10/50 km 阈值两侧各 **2 km**；这 2 km 是最小复核带，不是假定的已证明误差上界。复核带内全部点采用测地复核距离。

投影误差上界必须有适用区域和投影尺度依据，200 点抽查本身不能证明上界。若无法建立可靠上界，改为对所有需分组的唯一坐标作测地岸距复核；若预计超预算，暂停该分组并报告，不能默认为投影分组正确。任何差异超过登记上界或复核仍无法确定分组时，标记不确定并暂停扩大计算。岸线细节不确定的案例不支持米级“上岸”结论。几何预检记录唯一位置数、复核带点数、局部岸线顶点数及实测吞吐，再估算 35 分钟阶段预算是否可行。

距离只需按位置计算一次，各模型复用；其算法与版本冻结在诊断输出中。五模型原 `land_mass` 直接读取，保留原评分岸线版本，不拿新几何重新计算它。

### 5.2 统一评分及不确定性

五模型必须在同一组 33,971 个键上完全对齐。每组、每模型沿用当前 MDN 的 **先 ID 内平均、再 ID 等权**；不沿用早期 E7 的 cell 等权列，不以配对总数加权替代。

对指标 s、分组 g：

`S(model,g) = mean_over_IDs_with_group(mean_over_that_ID_queries_in_g(s))`。

输出 ES（km，越低越好）、H90（实际命中率）、90% 椭圆面积（km²）、预测陆地概率和域外概率，以及配对数、ID 数、最大 ID 配对占比。面积与命中率始终一起解释；land_mass 不叫真实搁浅概率。不同组有不同 ID 组成，各组均值不能直接按配对数加权还原全局。

主要诊断对照为 MDN22−LocalGaussian、LocalGaussian−ExactPoint；MDN1、EndpointCI 提供上下文。不是新的模型验收或选择规则。

- 在支持足够的组中，对 **45 个验证 ID 整簇有放回抽样 5,000 次，种子 20261110**，使用一套共同抽样序列，每次同一批 ID 同时用于所有模型与分组；重复抽到的 ID 按次数参与平均。若任一需要区间的分组为空，整次共同抽样重抽并记录次数，不能各组独立重抽。报告 95% percentile 区间，不把小时配对独立 bootstrap。
- 分组少于 **10 个独立 ID**时只报告描述统计与案例，不报告显著性或稳定的覆盖率结论。该数值是本轮报告门槛，不是“10 个就足够”的统计定理。
- 近岸/离岸误差差异可能来自地理、流态及样本组成；补充只在两组均有记录的 ID 内计算近岸减离岸差，再 ID 等权。共同 ID <10 时同样仅描述，不声称搁浅造成性能下降。
- 复用主计算/已有复核评分进行组级数值差检查；差异与数值复核差同量级时，结论为“当前精度下方向不稳”。不为诊断增加 ES 样本或重跑积分。
- 这些是重复使用开发验证集的探索性结果，不作为独立最终检验；不据此改变 MDN22 或历史验收结果。

## 7. 资源预算（本轮独立上限）

既往 MDN 的资源放宽不适用于本诊断。不加载模型、不训练，不新增预测或 ES/区域积分抽样；仅执行本方案规定的 ID 整簇 bootstrap。

| 计算阶段 | 累计可分配墙钟时间 |
|---|---:|
| 输入哈希、身份与文件结构检查 | 15 分钟 |
| 元数据、事件筛查与时间关联 | 20 分钟 |
| 完整候选原因与缺失对账 | 30 分钟 |
| 岸距计算、缓存评分汇总与 bootstrap | 35 分钟 |
| 独立复核与输出验证 | 20 分钟 |
| **全部计算合计硬上限** | **120 分钟** |

预计整体工程与案例审阅 **半天，最多 6 小时主动工作时间**，包括实现、计算、复核与写报告；预算是预计范围，不是已经实测的性能。输入结构核查与前 10 个排序 ID 的诊断耗时计入预算，达到 10 分钟即估算全量耗时；不得因试查方便改变完整统计样本。

- CPU 最多 2 个工作进程，BLAS 每进程 1 线程；单个 ID 串行读取并释放，禁止复制全量轨迹到内存。
- 总 RSS 预检 4 GiB、硬上限 6 GiB；新产物预计 <500 MiB、硬上限 1 GiB；磁盘剩余始终 ≥2 GiB。
- 默认不下载轨迹，优先复用已核验的官方目录和缓存。仅在缺证时，最多 10 次官方元数据请求、每次最多 30 秒、失败最多再试 1 次；总网络时间 ≤10 分钟、总新增下载 ≤100 MiB，计入上述 120 分钟。不得扫描新 ID、下载全球小时数据或另行采购/使用云算力。
- 若深水/浅滩解释需要当前没有的水深证据，记“未解决”；本轮不新增海底地形资料工程。

## 8. 验收与停止标准

**完成标准不是证明搁浅有害，而是问题有可追溯答案。**

完整交付须满足：383 个 ID 均有明确状态（允许明确的“未解决”）；训练/验证原键集合完全对账；候选流程和所有缺失/排除原因计数守恒；五模型原指标复现；所有原文件不变；未访问最终测试；资源账清楚。不存在搁浅证据或样本不足也可作为有效结论，不为获得显著结果继续扩展。

科学停止：

1. 官方记录或轨迹不足以定位事件时间：保留 ID 级状态，不硬做七天事件标签。
2. 组内独立 ID <10、无法估计可靠区间：停止该组推断，仅描述；不调宽阈值凑样本。
3. 缺失终点无法观测：停止其 ES/覆盖率讨论，不插值或用模型补真值。
4. 候选账本不覆盖完全被资格排除的其他 ID：如实限定到当前 383 个，不擅自扩到 3,224 个开发 ID。
5. 相关性结果只能支持“存在近岸局限/样本选择风险”；因果与修复收益需要另一项预先批准的实验，本轮不做。

工程停止：来源哈希变化、名册/角色/键不一致、候选分母无法对账、几何复核失败、原全局评分无法复现、发现需要写原文件、任何 final-test 访问、预计超预算，立即停止受影响步骤并报告。保留已经通过的独立部分，标注缺失；不降低样本数、替换岸线、放宽资格或改变精度来“完成”。若发现实质数据问题，只交证据与影响键，不修复或重训。预算达到上限即交部分报告，由用户决定是否追加。

## 9. 文献依据与本轮自定部分

- [Brolly (2023), §§4.4.1–4.4.2](https://arxiv.org/html/2303.11480v2)：Gaussian/MDN 支持可延伸到陆地；模拟时拒绝陆地落点并不等于识别真实搁浅。本轮保留完整冻结概率。
- [Lumpkin, Maximenko & Pazos (2012), Evaluating Where and Why Drifters Die](https://doi.org/10.1175/JTECH-D-11-00100.1)：官方终止原因、停滞筛查与人工判断；停止发报包含未识别的搁浅可能。因此原标记、轨迹和未知状态应分开。
- [NOAA hourly metadata](https://data.pmel.noaa.gov/generic/erddap/info/gdp_hourly_velocities/index.html)：`typedeath` 编码及数据字段语义；具体 ID 判据以项目已保存且身份核实的来源版本为准，不以该较旧镜像覆盖现有记录。
- [NOAA hourly product](https://www.aoml.noaa.gov/phod/gdp/hourly_data.php)：小时位置为经质量控制与处理的规则时间估计，非每小时独立原始定位。

50 km 主分组、10 km 细分、5 km 筛查、覆盖率、12 个案例、10 ID 报告门槛、bootstrap 与资源上限均是本轮为了范围可控而预先提出的工程/分析选择，不宣称为文献证明的普适物理阈值。
