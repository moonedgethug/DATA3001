## 1. 研究问题与解释边界

核心目标仍是 **where things end up**：给定真实出发位置，预测同类 drifter 七天后的完整落点概率分布。本轮研究：一个在全训练区域共享参数、随出发经纬度连续变化的高斯混合转移分布，能否在保持实际命中率和预测区域面积的同时降低 Energy Score（ES）？

预先区分两项比较：

1. **MDN1 对 LocalGaussian**：用网络学习位置与分布参数的关系，是否优于逐查询近邻估计？两者都是条件单高斯，但估计方式、支撑使用和正则化不同，不能把差异单独归因于“神经网络”或某一项操作。
2. **MDN-K 对 MDN1**：在同一输入、训练程序及隐藏层结构下，增加混合成分是否值得？K 增加也会增加输出层参数；不是仅改变真实物理峰数的实验。

ExactPoint、EndpointCI 是必须保留的经验预测对照。只超过 LocalGaussian、仍不及这两个对照，不构成整体预测改善。

本轮仍是七天、位置条件、时间齐次的 Markov 转移核估计；不训练轨迹递归网络，不证明位置过程严格满足 Markov 性，也不将七天核自动认定为可准确迭代到任意时长。drifter 是研究对象/输运代理，不把结果当作已验证的油污风化模型。

## 2. K 的含义与文献依据

MDN1 / MDN32 分别表示每个出发位置的条件分布由 1 / 32 个高斯成分表示。每个成分有自己的二维均值、完整协方差和混合概率；这些量随出发位置变化。32 不是隐藏层数，不是预设的 32 个地理终点，也不保证出现 32 个峰；成分可以重叠或权重很小。

[Brolly (2023), §4.2–4.3](https://arxiv.org/html/2303.11480v2) 使用经纬度输入、四天位移输出、条件高斯混合和负对数似然训练，并比较 MDN1/MDN32。论文明确说成分数可以优化；32 来自试验中的表达能力判断，不是通用最优值。其六个隐藏层宽度为 256/256/256/256/512/512，采用 tanh、softmax 混合概率和 Cholesky 协方差。

[作者 modelling.py](https://github.com/mtbrolly/transition_density/blob/master/modelling.py) 与论文的早停留出比例存在差异：代码是 20%，论文是 10%。因此本轮不照搬其数据划分，采用下文明确的整 ID 留出和时间验证。代码文件核对的 Git blob 为 `96637786bf5fee3fc7d98c189980bb1072d6d8c1`。

借鉴的是“位置 → 条件分布参数”的方法，不声称复现其全球、四天、大数据实验。本轮网络规模、协方差下限、K 候选、训练参数和预算都是**待批准的本项目选择**，不是 Brolly 给出的最优值。

## 6. 数学定义与网络

### 6.1 坐标和转移核

对每条训练配对 `(x_i, y_i)`，x 是其自身真实起点，y 是原始七天终点。沿用 WGS84 坐标变换：

\[
v_i=T_{x_i}(y_i)=d_i(\sin a_i,\cos a_i)\quad[\mathrm{km}],
\]

d、a 分别为 WGS84 逆解距离和从北顺时针方位角；G_x 是对应 WGS84 正解。训练学习该条记录自身的位移，不把 donor 轨迹搬到别的查询起点。

仅用当前拟合子池的配对等权均值和总体标准差，分别逐维标准化起点 lon/lat 和 v：`z_x=(x-m_x)/s_x`，`z_v=(v-m_v)/s_v`。不使用验证坐标来拟合标准化器。零或非有限尺度须暂停，不能临时换特征。该区域不做经度 ±360° 数据复制。

\[
p_\theta(z_v\mid z_x)=\sum_{k=1}^{K}\pi_k(z_x)
\mathcal N_2(z_v;\mu_k(z_x),\Sigma_k(z_x)),
\quad Y=G_x\{m_v+\operatorname{diag}(s_v)Z\}.
\]

所有 ES、面积和命中判断使用映回地理位置后的 Y。训练似然定义在标准化位移坐标上；记录原 km 位移密度时加回尺度 Jacobian，不把它直接称为每平方公里地表密度。

### 6.2 固定网络结构

`2 inputs → Dense(64), tanh → Dense(64), tanh → Dense(6K)`。

输出每个成分的一个 logit、两个均值和三个下三角参数。混合权重用 softmax；均值不限制在样本范围内。协方差为

\[
L_k=\begin{pmatrix}\mathrm{softplus}(a_k)&0\\b_k&\mathrm{softplus}(c_k)\end{pmatrix},
\qquad \Sigma_k=L_k L_k^T+10^{-3}I_2.
\]

这是**明确的协方差下限正则化**：在标准化位移空间中最小特征值至少 0.001，防止某个成分收缩到单点获取极大似然。它不是定位 error，不把它描述为数据事实。本轮不搜索该下限；K=1 也使用相同规则。报告下限附近的成分概率质量，若模型改善/失败可能受此限制，结论须保留这一条件，不擅自调整。

各 K 的网络参数数量为 `4352 + 390K`：4,742 / 5,132 / 5,912 / 7,472 / 10,592 / 16,832。K=1 的 logit 恒给出权重 1，保留统一输出接口。不加入 dropout、BatchNorm、残差、预训练、额外空间核或多个网络的平均。

初始化固定：隐藏层 Xavier uniform、bias=0；均值头权重 N(0,0.01²)、bias N(0,0.5²)，用于打破成分对称；logit 头权重和 bias=0；协方差头权重=0，off-diagonal bias=0，diagonal bias 使初始 `LLᵀ+0.001I=I`。全部随机量由登记种子产生，不用验证落点或对照模型的预测来初始化。

## 7. 训练、早停和完整样本重拟合

训练目标是配对等权负对数似然（NLL）：

\[
\mathcal L(\theta)=-\frac1n\sum_{i=1}^n
\log\sum_{k=1}^K\pi_k(z_{x_i})\mathcal N_2(z_{v_i};\mu_k,\Sigma_k).
\]

NLL 用 log-softmax、logsumexp 和 Cholesky 求解，不能先算极小概率再取 log。NLL 用于训练/早停；ES 用于公共模型选择和最终评价。ExactPoint 没有同类连续密度，不与其比较 NLL。

| 项目 | 固定值 |
|---|---|
| 优化器 | AdamW；lr=0.001，betas=(0.9,0.999)，eps=1e−8 |
| 正则化 | weight decay=1e−4，仅作用于权重矩阵，bias 不衰减；这是附加学习限制 |
| batch | 4,096；每 epoch 无放回打乱，保留不足整批的尾批，不过采样短 ID |
| 梯度 | 全参数 L2 norm clip=5；记录触发率；非有限梯度暂停 |
| epoch | 最多 500；每 epoch 在完整早停子集评估一次 |
| 早停 | drifter 等权 NLL；patience=30；改善至少 1e−4 nats/配对才重置耐心计数；保存数值最小 NLL 的 epoch，精确并列取更早者 |
| 初始化种子 | 20261121、20261122、20261123；角色/K 派生流登记在 manifest |
| 数值环境 | 当前 PyTorch 2.14.1；CPU float64 训练、推断和评分；固定版本、线程与随机状态，不在同一实验中切换 MPS/float32 |

AdamW 的衰减是正则化，不等同于没有约束的纯最大似然。每个 epoch 每条配对出现一次；尾批损失按实际样本数与标准 batch 大小比例处理，不能让少量尾批记录额外获得一整批权重。

每个拟合角色、每个 K 使用相同的以下程序：

1. **早停留出**：在该角色训练 ID 中，以 `SHA256("mdn_s5_e3_stop_v1|"+canonical_id)` 排序，前 `ceil(0.1D)` 个 ID 作为早停子集，余下 ID 为优化子集。canonical_id 是无小数点的整数十进制字符串；按哈希十六进制升序，哈希并列按 ID 数值升序。按完整 ID 划分；不随机拆小时配对。分别为 C_T0 24 个、C_T1 28 个、外层训练池 34 个早停 ID。名单在读取任何该角色验证落点前冻结。
2. 三个种子各自在全部优化子集上训练，标准化只拟合优化子集。早停子集只提供 NLL，不提供梯度。以最低早停 drifter 等权 NLL 选择种子和对应 epoch e；并列取编号小的种子。保留三个种子的全曲线和终止状态，不平均三个模型。
3. **完整重拟合**：重新初始化该种子，标准化改由该角色全部训练配对拟合，在全部训练配对上恰好训练 e 个 epoch。早停子集现在回到训练池；不再查看该角色验证集来选择 epoch。最终用于时间验证/外层预测的是这个完整重拟合模型，而不是只见过 90% ID 的早停检查点。
4. 若某种子达到 500 epoch 而未触发早停，保留其最佳 epoch、标记 `epoch_cap_reached`；允许按同一规则比较，但不能声称已优化至收敛。如果选中的种子触顶且最佳 epoch 位于最后 30 epoch，先报告潜在欠训练，**不进入完整评分或自动延长训练**。数值失败、来源失败不视作某 K 统计表现差，应暂停修复后按同一合同恢复。

拟议工作量：内层 `6个K候选 × 2窗口 × (3早停训练+1完整重拟合)=48` 次拟合；外层全部六个 K 同样各 4 次，共 24 次；**最多 72 次有界拟合**，不含只用于工程检查的试跑。三种子比较检验优化敏感性，但没有给所有种子分别计算完整 ES，因此不声称量化了全量 ES 的种子不确定性。

随机流使用 SHA256 的稳定派生，不使用进程相关的 Python hash：输入 UTF-8 字符串 `mdn_s5_e3_v1|purpose|role|K|base_seed|query_key|replicate`，不适用字段为空，取 digest 前 8 bytes 的 little-endian 无符号整数；要求 32-bit 的库再取模 2³²。purpose 分开 init、shuffle、ES、region、IID、audit；query_key 用冻结源键按十进制字段拼接。全部清单写入 manifest。完整重拟合从该种子的初始状态重新开始，不沿用早停模型的优化器或权重。

防过拟合依靠小网络、协方差下限、权重衰减、整 ID 早停、时间验证和偏向简单模型的选择规则；没有哪一项能保证绝不过拟合。不能把 265,393 条重叠配对称作 265,393 个独立实验。

## 8. 内层选择 K 与外层比较

### 8.1 全量 ES，固定选择顺序

每个 K 在 C_T0/C_T1 的全部 86,373 条查询上评分，不用训练 NLL 排名预先淘汰 K。跨窗口分数沿用 E2：先对每个 `(ID,窗口)` 的查询平均；同 ID 的窗口均值再平均；最后对 104 个不同 ID 等权。

\[
\bar S_K=\frac1{|D|}\sum_{d\in D}\frac1{|F_d|}\sum_{f\in F_d}
\frac1{n_{df}}\sum_{t\in(d,f)} ES_{Kdft}.
\]

唯一选择路径：

1. MDN1 始终为参照。K>1 要求两个时间窗口的 ES 均不高于 MDN1，且合并 ES 至少相对下降 0.1%，数值上可分辨，才有晋级资格。
2. 在 MDN1 与具备资格的 K 中找到合并 ES 最低的 b；数值等价取更小 K。
3. 固定种子 20261124，按 104 个 ID 配对 bootstrap 10,000 次，保留每个 ID 在两个窗口的整体记录，估计每个候选与 b 的差值标准误。选择满足 `S_K−S_b ≤ SE(S_K−S_b)` 的最小 K。这是保守的一倍标准误选择，不是独立显著性检验。
4. 若暂选 K>1，才为它和 MDN1 在两个完整时间窗口构造 90% 区域。两个窗口分别要求：H90 不下降、平均面积不增加、陆地和域外概率质量各新增不超过 0.01。微小差异若数值上不能判断，则不晋级。
5. 第 4 步不过，预定 `K*=1`，不轮流试其余 K 来寻找通过门槛者。若 K*=1，明确“本轮选择不支持增加成分”。这里是**全局模型选择结果**，不是把不利查询替换成 MDN1。

区域构造函数不接收真实终点，不依据实际命中扩大椭圆。参数、预测和积分流先冻结，后评分。

### 8.2 外层报告范围

K*、全部训练超参数、源哈希、早停规则及数值层级在新 MDN 外层评分前冻结。随后六个 K 均用 2001–2019 全部训练数据按第 7 节重拟合；全部分布冻结后，统一评估 2020–2022 全部查询。

- 主模型是**事先选定的 MDN-K***，主比较是它与 LocalGaussian、ExactPoint、EndpointCI。
- MDN1 是估计方式对照；其余五个 K 的外层完整表格用于展示复杂度敏感性，不因其外层 ES 更好而改选 K*。
- K*=1 时，MDN-K* 是 MDN1 的别名，不复制成“两个独立成功模型”。
- 内层未选的 K 若外层更好，记为探索性现象；本轮不追加局部 K 搜索、重复训练或更换最终模型。如此既回应“比较多组参数”，又避免把外层当调参集。

## 9. 共同评分、90% 区域和概率处理

ES 完全沿用 E1/E2 定义；ψ 是零高程 WGS84 ECEF，单位 km，使用弦距离，Y/Y′ 独立：

\[
ES(F,y)=E\|\psi(Y)-\psi(y)\|-\tfrac12E\|\psi(Y)-\psi(Y')\|.
\]

不改成平方距离、经纬度欧氏距离、Brier 或平均位置误差。外层每项 L 统一为 `mean_ID(mean_queries_in_ID(L))`；所有模型使用相同 33,971 个键及相同 45 ID 权重。

90% 区域沿用 **单个公共定义的椭圆**：LAEA 中心 `(−75°,35°)`、单位 km。以完整预测分布 U 的均值 m、协方差 S 定义

\[
q_{.9}=\inf\{q:P_F[(U-m)^TS^{-1}(U-m)\le q]\ge.9\},
\quad R_{.9}=\{u:(u-m)^TS^{-1}(u-m)\le q_{.9}\}.
\]

面积 `π q_.9 sqrt(det S)` km²；实际命中用精确验证终点判断。混合模型 q 必须由自身完整分布得到，不能套用 χ²₂(0.9)，也不能改为各高斯椭圆并集。ExactPoint 维持真实原子并列导致 ≥90% 的既有处理。

单椭圆会包含多个峰之间的低密度间隙，因此本轮的面积结论仅针对这个固定区域定义，不等于多峰模型最小高密度区域的优劣。不得为展示 MDN 优势临时切换成 HDR。0.5° cell 仅用于展示；中心、协方差、q 均不得用验证终点校准。

完整概率保留：陆地、域外、远尾全部计入分布、ES 和区域，不拒绝抽样、不截断、不对海洋重新归一化，不把域外概率冒充 observed first-exit E。沿用当前无 observed-E 的连续评估 cohort；若来源核对发现真实退出标签语义不一致，暂停而非给 E 编造坐标。模拟概率落到陆地不等于真实搁浅。

保留旧辅助诊断 `ES/100 + squared ECEF mean error/100²`（两份独立均值估计处理模拟偏差），不参与 K 选择或验收。

## 10. ES 计算、精度和复用

### 10.1 本轮预先声明的积分方式

E2 的完整成分对求和代价随 K² 增长，直接复制到 K=32 不合适。本轮 MDN 拟采用**从完整混合分布直接抽样**计算同一 ES；这是新的数值积分实现，需先验证，不宣称与旧积分逐位相同。

每个查询用 6 维 scrambled Sobol 节点：第一、四个坐标分别按 π 的累积分布选择成分，另外两对坐标变换为独立二维标准正态，得到 Y、Y′。每节点计算 `d(Y,y)−0.5d(Y,Y′)`。两个半部不得复用同一成分选择或同一正态抽样；成分相同的事件也必须包含。8 个独立 scramble replicate 用于误差估计，查询之间采用独立流；候选之间允许预声明的共同随机数以降低配对差方差。

π 的所有成分参与 CDF；不能裁剪小权重、把多个成分合并或固定只抽“大峰”。有限积分中某小成分未被抽到是数值误差问题，不是删除该概率。完整理论混合分布与训练权重保持不变。计算约为 O(N log K) 的成分选择、2N 次地理映射和 O(N) 距离，而非 K²N 距离；这是操作量收益，不是实际加速承诺。

预声明 ES 总节点 N={65,536,131,072,262,144}，均分到 8 replicate；区域总节点 M 为同一集合，使用独立 3 维混合抽样流；IID checker 固定 65,536 独立样本/查询。N、M 是整套分布的积分节点数，不再是每个成分的节点数；这与 E2 的含义不同，**精度验收门槛不放宽**。先按固定试跑检验各 K 的最小合格层级，采用对全部 K 都足够的共同 N、M，在正式评分前冻结。最高层仍不够时暂停，不自行增加层级。

### 10.2 数值验收

沿用 E2 门槛并明确适用于本轮所有主比较：

1. 概率和误差 ≤1e−10；协方差对称、有限并满足声明下限；原始点地理往返误差 ≤1e−6 km。
2. 聚合 ES 配对差的 3 个估计数值标准误 ≤基准 ES 的 0.0001；独立重复差异 ≤所声称改善的 10%。数值方差按 ID/查询汇总权重平方及 replicate 的完整配对差计算，不将 Sobol 节点当独立观测。
3. 区域 IID checker 的 Wilson 95% 区间半宽 h≤0.005；沿用加权 `distance(p_hat,[.90,.90+b])+h ≤0.005`，连续 MDN 的真实边界原子质量 b=0。
4. 独立区域重建加权命中分歧 ≤0.001，平均面积相对变化 ≤0.005；声称的非零质量改善还须数值误差不超过其 10%。陆地/域外聚合数值不确定性分别 ≤0.001。
5. 近零科学效应不可分辨时报告不确定，不为了显著而继续追加积分；基本精度未达到则是工程未完成，不能当作无改善结论。

检查包含 K=1、重复成分、强分离多峰、不均衡/极小 π、接近下限协方差、远尾与地理边界 fixtures；二维各向同性 K=1 用解析距离矩作单元参考，地理混合用独立 IID 抽样复核。另从每个内层窗口 64 个固定试跑键中取索引 0、21、42、63，共 8 键，对六 K 测试包用完整成分对加权积分作另一计算路径（每组件/组件对 8,192 节点、8 replicate），差异要求不超过两种估计合并的 3 个数值标准误。这个低成本交叉实现检查不替代正式精度门槛。不得仅验证同一抽样函数调用两次。

### 10.3 复用与缓存

只读引用 E2 完成运行 `local_gmm_s5_e2_vector_20261107T133426Z` 的 A/C/G1 参数、预测和逐查询评分，前提是角色、键、分布、权重、地理定义和精度完全一致。核对后复用其已有独立数值复核；不能把常数汇总表抄入而无逐 ID 配对证据。内层缺失的控制量只在实际需要时计算，不能声称有未做过的内层对照。

MDN 每角色训练目标变换只做一次，网络按批次一次性输出所有查询参数；缓存紧凑参数、随机流键和逐查询 replicate 统计，不保存全部积分点云。独立数值复算不重新训练网络。复用基准时，它与 MDN 不共享随机流，配对数值误差须按独立积分方差处理，不能假装享受共同随机数收益。

## 11. 验收标准与统计解释

主比较按 **LocalGaussian → ExactPoint → EndpointCI** 的固定顺序判断。前一个未达到全部门槛时，后续差异仍展示，但不据此宣称整体胜出。MDN-K* 对 MDN1 用于说明增加成分是否有用；其余 K 的外层排名均为探索性，不进行选择后的“赢家显著性”宣传。

外层按 45 个 ID 配对 bootstrap 10,000 次，种子 20261125，报告 ES 差、H90 差、平均面积比的双侧 percentile 95% 区间。每次保留一个 ID 的全部查询均值和所有模型配对。区间以已训练模型固定为条件，不包含重新训练不确定性，也不消除共同海洋强迫造成的 ID 间相关。

| 结论/验收 | 预先要求 |
|---|---|
| 工程完成 | 全部六 K、两个完整内层窗口及完整外层查询完成；来源、训练、冻结、精度、汇总与审计通过；没有隐去失败查询 |
| 对某基准有用的 ES 改善 | drifter 等权 ES 相对降低 ≥0.1%；配对 ES 差 95% 区间上界 <0；数值误差可分辨 |
| 观察到的质量不退化 | H90 点估计 ≥基准；平均 90% 面积点估计 ≤基准 |
| 不确定性门槛 | H90 差区间下界 ≥−0.01；面积比区间上界 ≤1.02 |
| 地理质量 | 新增陆地和新增域外概率质量各 ≤0.01；不能靠裁剪达标 |
| 整体可讨论保留 | 预选 MDN-K* 对 G/A/C 全部达到上述 ES、质量与地理门槛 |
| 支持增加成分 | K*>1 且外层对 MDN1 也通过同样 ES 与质量门槛；否则不宣称多峰扩展必要 |

1 个百分点和 2% 是区间容许范围，不允许用来掩盖点估计退化；“没有显著变差”不是非退化证据。ES 好但面积/命中变差，明确写 trade-off。若 K*=1，只检验单高斯网络能否改善预测。若无候选带来整体改善，保留负面证据并结束本轮，不自动进入第二轮参数搜索。

报告三个种子的早停 NLL 差异、训练/早停曲线、两个时间窗口一致性、逐 ID ES、成分概率熵及协方差下限质量。有效成分数只是模型诊断，不解释成真实洋流条数；0.5° 图上的视觉清晰也不替代评分。

正式训练的预算预测须使用各 K 前固定 5 epoch 的实测成本与已预留的 500 epoch 上限敏感性，显式计入三个初始化、完整重拟合、验证、I/O、选定 N/M 和全量独立复核。5 epoch 属于登记的正式训练前缀并保存可续进度，不额外抽样。阶段预计成本取操作分解与实测 p95 推算较大值，再加 1.5 倍余量；超过阶段/累计剩余额度时暂停，不强行开始昂贵评分。典型早停估计和 500 epoch 最坏情形分别报告，不假称已测得完整耗时。

- 训练一次一个进程，CPU 线程最多 4；数值评分先单进程，验证单/双 `spawn` 一致后最多两 worker，每 worker BLAS 线程 1；使用私有几何对象，不能跨线程共享可变几何状态。

- 试跑测得的正式训练/评分预估通过预算闸门后，才允许在本合同批准范围内继续；不要求无意义的逐阶段再次确认，遇到合同变化才请求审阅。
