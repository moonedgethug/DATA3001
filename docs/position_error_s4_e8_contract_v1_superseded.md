## 1. 研究问题与边界

给定 drifter 的记录起点 lon/lat，预测七天后落点。检验：在相同训练配对、近邻集合和投票规则下，把历史终点的位置不确定性加入经验 Markov 转移分布，是否改善未见 drifter 的落点分布预测。

本轮是一个小规模、预先定义的增量假设检验，不预设 error 有用，也不通过反复调大误差来追求更好的图。仍估计固定步长的 Markov transition kernel `K_7(x, A)`；从连续位置出发、向连续位置集合给概率，不必是有限 cell 矩阵。Markov 假设本身并未被这轮检验证明。

| 固定内容 | 定义 |
|---|---|
| 数据 | cleaned v7；原有 pooled 资格、完整七天配对及退出规则 |
| 拟合/验证 | 2001–2019 / 2020–2022；whole-ID 不重叠；排除跨边界标签 |
| 本轮时距 | 仅 7 天，承接 E7；不追加 30 天或小步长迭代 |
| 近邻 | 真实起点间 WGS84 距离；100 km 硬上限；冻结 E7 的 k=8,000 及 cutoff ties |
| 训练贡献 | 每个历史观测配对等票；不改变成 EqualID 训练、不重新调 k |
| 新增信息 | 历史终点 err_lon/err_lat 的测量不确定性；无新的环境变量 |
| 不进行 | 轨迹平移、B1/B2 融合、MDN、拟合单个高斯运动模型、带宽/核家族搜索 |
| 展示 | 0.5° 概率汇总图；不用于主评分、区域面积或验证权重 |

**本轮建议只改变历史终点的不确定性表示。** 起点仍用真实记录坐标选择同一批近邻；起点 error 只审计，不用于改 donor 或权重。理由是先隔离一个效果，且小时产品由回顾性插值产生，释放时能否获得同样的起点 CI 尚未证明。起点 CI 改变借用方式属于后续独立增量，不能把两个作用合在一起后都归功于 error。此范围需要随本 contract 一并确认。

## 3. CI 的统计含义与使用方法（G0 通过后）

设已确认的经纬度 95% 半宽为 `h_lon, h_lat`。先按每条位置的纬度，用 WGS84 局部坐标换为东西/南北距离半宽 `h_E, h_N`，单位 km；不能将经度直接当纬度距离使用。

本轮固定一个测量不确定性工作核：

\[
R_r=\mathrm{diag}\{(h_{E,r}/1.959964)^2,(h_{N,r}/1.959964)^2\},\qquad
\epsilon_r\sim N_2(0,R_r).
\]

从记录终点 `y_r` 沿局部东西/南北扰动，通过 WGS84 地理映射得到随机位置 `T(y_r, epsilon_r)`。其分布记作 `Q_r`。这让单个观测附近中心较高、外围较低，但**完整预测仍是大量历史终点核的混合，可以有多峰**；没有用一个高斯拟合整片洋流。

此正态形状只是从边际 CI 构造可计算分布的工作假设。95% CI 不能唯一确定这个分布；也不能由此宣称得到了真实位置的贝叶斯后验。经纬两轴各 95% 的矩形不等于二维 95% 区域；更不能将它们直接画成七天的圆。

原始端点本身已有估计误差，再加入核并不是自动去除了测量误差。本轮检验的是一种 **CI 辅助的经验分布表示**，不是反卷积或已识别的潜在真实输运模型。若改进只出现在误差扩散后的评分中，不算物理预测能力已提高。

误差某轴缺失、负值或未解释的零值时，整条记录保留为原始点质量 `delta_y`，标记 error-unavailable；不取绝对值、不删配对、不用验证资料填补、不偷偷设最小扩散半径。有效宽度很小也不主动放大。

## 4. 对照与识别逻辑

设同一个起点的冻结 donor 集为 N(x)，n 为配对数，所有组使用同一票重 1/n。

| 模型 | 分布表示 | 能回答的问题 |
|---|---|---|
| A：ExactPoint | E7 的原始历史终点点质量 | 不使用 error 的主要对照 |
| B：EndpointCI | 每个可用终点替换为自己的 Q_r；其余仍为点 | 加入每条记录 CI 是否改善预测，**唯一主候选** |
| C：MatchedSpread | 使用相同 donor，每个可用终点采用共同协方差 R_bar | 改善是否只是一般扩散，而不是不同记录的 error 信息 |
| B2Point | 旧全年 B2 的原 donor 规则、精确历史终点表示 | 历史锚点，只作次要对照 |

\[
F_A=\frac1n\sum_r\delta_{y_r},\qquad
F_B=\frac1n\sum_r Q_r .
\]

对 C，`R_bar` 是该 query 可用 donor 的局部东西/南北 `R_r` 的算术平均；将同一 `R_bar` 赋给所有可用 donor。不可用 donor 与 B 一样保留点质量。这样保持相同总票重、缺失处理和平均核方差，仅移除“哪个终点对应多大 error”的联系。它不保证球面映射后的高阶矩完全相等；必须检查并报告差别。

E donor 在所有组中仍为 E，不对它施加位置核。A/B/C 的 donor、原始权重和 E 概率必须逐 query 完全一致。无 donor 的行报告 unsupported，不扩大 100 km，也不删掉后再报更好分数。

主要检验为 B 对 A；B 对 C 是预先指定的解释性比较。B2 不参与候选选择。不能在看到外层表现后从 B/C 中择优并把胜者改称原假设。

## 5. 主评分与辅助评分

### 5.1 Energy Score：主判据

把精确经纬度映射为 WGS84 地心坐标 `z=psi(y)`，单位 km，采用普通欧氏距离：

\[
ES(F,y)=E\|Z-\psi(y)\|-\tfrac12 E\|Z-Z'\|,\quad Z,Z'\overset{iid}{\sim}\psi_\# F.
\]

数值越小越好。地心弦长不同于大圆距离，但其欧氏形式使 proper-score 的适用条件清楚，且与旧辅助代码的坐标体系一致；所有组相同。不得在度数上直接计算距离。参见 [Gneiting & Raftery (2007)](https://sites.stat.washington.edu/raftery/Research/PDF/Gneiting2007jasa.pdf)。

主分析用记录的真实验证落点坐标 y。合法但被模型赋零概率或位于低密度尾部的落点继续计入，不能删除。

### 5.2 验证端 CI：仅作稳健性分析

外层预测、区域及参数全部冻结后，才读取验证 endpoint error。对所有模型使用同一个、固定方法构造的 Q_obs，报告 `ES_soft = E_{Y~Q_obs} ES(F,Y)` 和 `Q_obs(R90)`。

这不是 CI 相交率，也不把“两个区域有重叠”算命中。它是对观测不确定性的敏感性分析，不替代实际点命中率。它也不是无需假设的真实状态评分校正；观察误差会改变评分对象，[Ferro (2017)](https://doi.org/10.1002/qj.3115) 解释了这种区别。只有 ES_soft 变好不能作为本轮成功结论。

### 5.3 旧组合 loss

现有 `markov_scoring.py` 的组合实际为：

\[
L_{aux}=ES/100+\|E(Z)-\psi(y)\|^2/100^2 .
\]

保留固定 100 km 尺度和相同公式，但用精确位置，不再使用 cell 中心。它不是简单的 `E[d+d^2]`；后者不能直接当作严格评价完整分布的标准。组合只辅助报告，不选择模型或翻转主 ES 结论。对中心对称的小扰动，均值项通常几乎不变，不能期待它提供另一份独立增益证据。

## 6. 不依赖 cell 的 90% 区域、命中率与面积

### 6.1 为什么本轮不直接对 raw points 计算 HDR

A 是离散点分布；其包含 90% 点质量的集合可具有零面积。B 是连续/混合分布。直接比较两者的最高密度区域面积会把表示差异当作预测能力。若采用 HDR，必须额外规定所有对照共同的连续密度估计方法；这是本轮暂不引入的另一个估计选择。[Hyndman 的 HDR 方法](https://robjhyndman.com/papers/hdrgraph.pdf) 依赖明确的密度。

### 6.2 建议采用共同的分布分位数椭圆

所有组使用同一规则，不需要新增带宽：

1. 将完整地理预测分布变换到固定 WGS84 Lambert azimuthal equal-area 平面，中心 `lon_0=-75°, lat_0=35°`，单位 km。投影只用于几何；不用于 donor 选择或地心 ES。
2. 由该分布得到均值 m 和协方差 S；取随机预测落点的 `D²=(U-m)' S^{-1}(U-m)` 的 90% 分位数 q90。
3. 定义 `R90={u: (u-m)' S^{-1}(u-m)<=q90}`。正定时平面面积为 `pi*q90*sqrt(det(S))` km²；等面积投影用于对应地表面积。先验证全域无投影奇点。
4. q90 来自模型自己的整个落点分布，**不使用验证端点，不固定套用高斯 chi-square 分位数**。因此完整运动分布不需要服从高斯。原点分布的 cutoff ties 全保留，并报告实际包含的模型概率。
5. 这不是“把两个观测 CI 画成圆”，而是从所有可能去向计算共同的预测区域。它可能包含多峰之间的低概率水域，不能声称是最小面积或最佳搜索区域；本轮不再优化区域形状。

若分布退化为线/点，则用对应退化集合，面积记 0 并单独标识；不加任意方差下限。任何退化行仍计入 ES/实际命中率，不能靠它证明面积改善。若大量退化妨碍比较，停止并审阅，不改成 cell。

报告：实际点 `1{y in R90}`、drifter 等权 H90、平均/中位面积、分位数、区域包含的实际预测质量、与 0.90 的差、退化率、地理外溢。A 的实际模型质量可能略超过 90%，不能说每个原子预测都恰好 90%。

0.5° 图只汇总完整概率并叠加上述连续边界、原始观测点和小比例的观测 CI 示意。**面积从连续区域计算，不数格子；命中从精确坐标判断，不查询所属 cell。**

## 7. 陆地、退出与未解析质量

保留原有 first-exit absorbing E 标签；不把 CI 核落到 D 外或陆地自动改成物理 E，也不生成整路径或新的搁浅标签。核只表示记录位置附近的测量不确定性，其陆地/D 外部分原样保留、单列概率；不截掉后悄悄归一化。主 ES 对完整地理部分评分，区域面积报总地表面积，并额外列出与冻结海域/陆地的交集面积。

E/U 没有虚构坐标。当前训练配对 E=0；运行时复核冻结队列的 E 情况。若存在真实 E，另报二分类退出 Brier、E 质量及对应命中，不把 E 强塞进 Energy Score。地理 ES/90% 区域必须明确是条件于非 E 的评价，并给出完整样本分母。由于 A/B/C 的 p_E 相同，不能通过更改退出质量制造空间改善。

任何新增 U、unsupported 或 NaN 都是工程未通过，不准删除这些行。数值积分尾部不得消失；若几何计算不能保留或可靠界定质量，停止该阶段。B 相对 A 的平均陆地/D 外质量增加超过 1 个百分点，不能认定为质量不退化；这是待批准的额外质量护栏。

## 8. 训练内验证、汇总口径和假设检验

继续使用冻结 E7 角色：内层 2001–2013 → 2014–2016、2001–2016 → 2017–2019；外层 2001–2019 → 2020–2022。内外层 whole-ID purge 和标签时间界限一致。当前外层有 33,971 个配对、45 个独立 ID；不把配对数当作独立样本量。锁定 final-test 不访问。

本轮不选择新的 k、扩散倍数或融合权重。CI 幅度倍率固定为 1；不把 source 单位疑点交给 CV 解决。内层只检验实现、数值精度、支持情况和效果稳定性；无论表现好坏均保存结果，不据此增加模型候选。G0 通过、工程检查通过后，外层按同一方法运行一次。

**为了满足 train/validation 主体不依赖 cell，建议把主汇总改成：每个 drifter 内合法预测时刻等权，再对 drifter 等权。**

\[
\bar L={1\over D}\sum_{d=1}^{D}{1\over n_d}\sum_{t=1}^{n_d}L_{dt}.
\]

这是相对于 E7 的一个显式评价变更：E7 曾按 ID × origin cell，再跨 origin cell 汇总。所有 A/B/C/B2 必须在本轮同一 case roster、同一新权重下重算；不能拿新 ES/命中率与历史表格直接相减。旧 cell 分层口径只可放在兼容性附表，不作为本轮验收。训练仍按配对等票，评价按 ID 等权；二者是不同选择，必须同时报告长记录主导程度。

主假设：令 `Delta=mean_d(ES_B,d - ES_A,d)`，检验 `H0: Delta>=0` 对 `H1: Delta<0`。保存每个 ID 的配对差值，以 whole-ID cluster bootstrap 10,000 次、seed 20261106 给出双侧 95% 区间；上界小于 0 才称本轮有明确改善证据。预测模型不在每次 bootstrap 内重拟合，区间只反映固定拟合下 held-out ID 的抽样不确定性。

同一次 ID 重抽样同时计算 H90 差值、平均面积比；所有时刻随 ID 整组进入，不能逐小时独立 bootstrap。另列逐年结果、逐 ID 差值及 leave-one-ID-out 敏感性，防止单条轨迹支配结论。共享洋流造成的 ID 间相关性仍是限制；2020–2022 已反复用于开发，不能把此 p/CI 当成未经选择的独立最终证据。

B 对 C、B 对 B2、ES_soft、旧组合 loss 均为预先列出的次要/解释性结果，不从多个指标中挑一个宣布成功。若 B 优于 A，但没有优于 C 的清楚证据，只能说“这种扩散有帮助”，不能说逐条 error 信息独有价值已被证明。

## 9. 预声明验收标准

下列均是拟议门槛，待用户审阅；不在看到外层结果后放宽。

| 判据 | 要求 |
|---|---|
| 科学与工程有效 | G0 通过；全部固定 case 保留；哈希/角色/质量守恒通过；数值精度达标 |
| ES 主改善 | B−A 的 ID 配对 95% 区间上界 < 0 |
| 实用收益 | 平均 ES 至少降低 0.1%，且超过所估计数值误差的 10 倍；否则称微小效应 |
| 命中率点估计 | H90_B >= H90_A |
| 面积点估计 | mean_area_B <= mean_area_A；不可用退化行制造优势 |
| 统计质量护栏 | H90 差值区间下界 >= −0.01；平均面积比区间上界 <= 1.02 |
| 原假设归因 | B 对 C 同时报告；没有证据超过 C，不宣称单条 CI 比一般扩散更有效 |

“1 个百分点 / 2%”是小幅非劣容忍界限，不等于数学上的零退化。必须同时满足点估计方向，才能写“观察到改善，且在上述容忍界限内支持非劣”；不得写成证明完全不退化。如果用户要求统计上严格零退化，将两条界限改为 0 和 1 后再锁定，而不是事后修改。

此外，模型标称含 90% 概率不保证实际 H90=90%。必须报告绝对 H90 与 90% 的差：即使相对改善，也不能把明显不足的绝对命中率称为已校准。若置信区间跨越零，写“证据不足”；不能写 error 肯定无效。若尺度不明，写“科学前提未满足”，不能作为 error 有/无作用的检验结论。

## 10. 数值方案与计算预算（批准后才实施）

复用冻结 E7 精确坐标、分割、donor 规则；另建 error 表和 score/region 模块，不修改既有模型。CI 核采用按 `(split, query_key, seed)` 固定的独立随机流，所有组共享 donor 抽样及标准扰动，以降低差值的积分噪声。worker 只写自己的分片，父进程做原子汇总，不并发修改同一个缓存。

ES 用独立的 Z、Z' 抽样估计两个期望，不为 8,000 donor 建每个 query 的全配对距离矩阵。每组从 M=4,096 开始；区域分位数从 16,384 开始，独立重复检查，最多 65,536。点原子集合的抽样按带放回的模型分布进行；不能把有限样本对角项混成另一个评分目标。

先检查不确定性可能带来的最大效果：在耦合 `Z_B=Z_A+扰动` 下，`|ES_B−ES_A| <= 2 E||Z_B−Z_A||`。使用实际映射后的位移估计并控制积分误差，不能只用典型中位数代替 query 级上界。若可解析/可靠界定的上界已低于实用收益门槛，记录“在该核设定下收益上限很小”，不花大成本追逐数值噪声。

| 阶段 | 固定预算与输出 |
|---|---|
| 来源门槛 | G0 未解除不运行下面阶段；不通过调参绕过 |
| 工程检查 | 质量守恒、CI 单位、精确坐标、时间单位、缺失回退、评分、椭圆、并行一致性 |
| 训练内资源试跑 | 固定选内层 query 128 条，按 ID/时间排序覆盖，不看结果挑样；最多 10 分钟 |
| 正式内层 + 外层 | 试跑外推总量 <= 2 小时才可在本预算内继续；8 GiB RAM，5 GiB 新输出 |
| 独立复核 | 最多 30 分钟；固定 128 条、独立积分种子及独立小规模精确求和参考 |

正式实验不允许靠删 query、减少合法 donor 或放弃异常记录达成预算。如果全量/精度不能同时满足，汇报实际瓶颈和预计耗时，等待审阅。上述是预算，不是已经测得的速度。

数值验收：概率和偏差 <=1e-10；A 的 donor/权重逐行重现 E7；小型离散例子的 ES 精确求和一致；主均值差的数值误差低于拟议实用 ES 门槛的 1/10；连续组区域质量估计误差 <=0.005；区域平均面积数值变化 <=0.5%、H90 数值变化 <=0.001。靠近边界的真实点单列，不能将边界数值波动当成增益。达不到时先标 numerical-inconclusive，不得报告科学通过。

在固定训练内代表案例上，相关性 rho=−0.5、+0.5 仅作假设敏感性检查，不选优、不回看外层改主假设；若结论随假设翻转，应报告依赖性并停止作强归因。不要在同一轮增加更多分布家族或尺度倍率。
