## 1. 审阅摘要与研究边界

通俗地说：过去把附近历史落点概括成一团，现在允许概括成两团或三团；每团有自己的位置、形状和概率。仍然使用同一批历史落点，每条配对仍投相同的一票。成分概率由这些记录拟合出来，不是重新引入 B1/B2 融合权重。

**不预设一定存在多个峰，更不预设 GMM 一定改善预测。** 两个成分也可能合成一个峰；成分不能直接解释为两股洋流。允许最终选择一个成分，以免为了多峰而强行增加复杂度。

| 项目 | 本轮固定定义 |
|---|---|
| 研究问题 | 同样的信息下，局部多成分高斯是否比单高斯及经验分布更适合七天落点预测？ |

## 2. 文献依据及证据边界

Brolly 使用高斯混合表示条件转移分布，但多成分模型的参数由神经网络随位置输出。因此该论文支持“混合分布能够表达非高斯转移”的研究方向，**不构成局部近邻 EM 方法已经有效的证据**。本轮是受其分布表示启发的独立检验，不是复现其 MDN。文献也不能证明 E1 的主要瓶颈一定是单高斯形状。[Brolly，§§3–4](https://arxiv.org/html/2303.11480v2)

普通 GMM 可用 EM 拟合；不受约束的高斯混合似然可能因协方差塌缩而无界，成分数也需要外部选择规则。BIC 的经典依据依赖相应独立样本假设；本项目重叠的小时配对不能直接作为大量独立证据。本轮不用逐查询 BIC 选 K，采用时间与 drifter ID 隔离的预测验证。[Gaussian mixture 官方说明](https://scikit-learn.org/stable/modules/mixture.html)

本文件的 K 上限、协方差下限、支撑阈值和预算是**预先提出的保守工程选择**，不是论文推荐值或统计保证；不能在看见外层结果后修改。

| 标签 | 分布 | 在 E2 中的用途 |
|---|---|---|
| A / ExactPoint | 同一批原始终点的等权点质量 | 必须保留的经验对照 |
| C / EndpointCI | 已修复的原始终点 error 核；不可用时该条保留为点质量 | 必须保留的误差分布对照 |
| G1 / LocalGaussian | E1 原公式的局部单高斯 | 直接检验增加成分是否有用 |
| G* / LocalGMM | 内层选出的 K*=1、2 或 3，加本文件明确的稳定性规则 | 本轮候选模型 |

C 继续使用修复后的 95% 边际 CI 半宽、除以 1.9599639845 转标准差、rho=0、宽度倍数 1 和既有 WGS84 扰动。不得用验证点的 error 放宽实际命中判定。

沿用 E1 的查询中心度量坐标。对 x 到 y_r 的 WGS84 逆测地线，令距离 d_r 为 km、初始方位角 a_r 自北顺时针：

\[
v_r=T_x(y_r)=d_r(\sin a_r,\cos a_r)^T.
\]

这只是表达原终点的坐标变换。对应的 WGS84 正测地线 G_x 把该向量映回地理位置，G_x(T_x(y_r))=y_r。

\[
f_K(v\mid x)=\sum_{k=1}^K\pi_k(x)\,\phi_2(v;\mu_k(x),\Sigma_k(x)),
\qquad \pi_k>0,\quad\sum_k\pi_k=1,
\qquad Y=G_x(V).
\]

每个查询单独拟合，近邻变化仍可能造成空间不连续；没有学到全局位置到参数的函数。正态密度定义在上述 km 坐标中，不是经纬度度数上的正态，也不是全球球面高斯密度。

G1 严格保留

\[
m_0=n^{-1}\sum_r v_r,\qquad S_0=n^{-1}\sum_r(v_r-m_0)(v_r-m_0)^T.
\]

协方差分母为 n。若 n<3、S0 有非正特征值、条件数>1e12 或地理变换非有限，则记录并暂停整轮；不修补 G1，不删该查询。

## 5. EM 拟合与显式协方差约束

### 5.1 为什么需要约束

一个很窄的成分可以只包住少量重复点，把训练似然推得很高，却不能预测新 drifter。为防止这种数值与统计退化，**拟议给 GMM 增加以下明确约束**；它不是 E1 已有规则，也不是纯粹不影响模型的计算技巧。

先作 S0=L0 L0^T 的 Cholesky 分解，令 z_r=L0^{-1}(v_r−m0)。在 z 空间拟合混合，组件协方差 B_k 满足

\[
B_k\succeq\alpha I,\qquad \alpha=0.01.
\]

映回原坐标：mu_k=m0+L0 a_k，Sigma_k=L0 B_k L0^T。因此 Sigma_k≽0.01 S0，即各方向标准差至少为局部总体相应标准差的 10%。这不是“增加 1% 的 error”，也不把所有组件强制为圆形。

alpha 本轮不搜索、不随外层结果调整。K=1 直接调用 E1 解析结果；其白化协方差为 I，下限不改变单高斯。双精度仅可对称化舍入误差，不另加 ridge、默认 `reg_covar`、协方差膨胀或尾部裁剪。

### 5.2 明确 EM 公式

最小化配对等权的平均负对数工作似然：

\[
\mathcal L_x=-\frac1n\sum_{r=1}^n\log\left[\sum_{k=1}^K\pi_k\phi_2(z_r;a_k,B_k)\right].
\]

白化变换的 Jacobian 对同一查询的各候选为常数，记录原 km 坐标似然时使用 log f_v=log f_z−log|L0|。训练似然仅用于 EM 和同 K 重启选择，不代替验证 ES；也不假设小时配对彼此独立。

E 步：

\[
r_{rk}=\frac{\pi_k\phi_2(z_r;a_k,B_k)}{\sum_l\pi_l\phi_2(z_r;a_l,B_l)},\qquad N_k=\sum_r r_{rk}.
\]

M 步：

\[
\pi_k=N_k/n,\quad a_k=\frac{\sum_r r_{rk}z_r}{N_k},\quad
B^{raw}_k=\frac{\sum_r r_{rk}(z_r-a_k)(z_r-a_k)^T}{N_k}.
\]

若 Braw=Q diag(lambda_j) Q^T，取

\[
B_k=Q\,\mathrm{diag}(\max(\lambda_j,0.01))\,Q^T.
\]

这是给定责任度时，在 B≽0.01I 约束下的协方差 M 步。保留完整协方差与所有记录；责任度是软分组，不把每条记录硬分到一个 endpoint 或删去尾部。

### 5.3 初始化、收敛和确定性

| 参数 | 固定规则 |
|---|---|
| K | 1、2、3；K=1 解析计算，K=2/3 运行以下流程 |
| 重启次数 | 5 次，全部执行，不因某次结果好就提前停止 |
| 初始均值 | 白化空间 k-means++ 播种：首点等概率，后续按距已选中心最近平方距离抽取；不额外运行 k-means |
| 初始权重 / 协方差 | 1/K；每成分 I |
| 迭代上限 | 每次重启最多 200 次完整 E/M 更新 |
| 收敛 | 平均 log likelihood 连续 5 次增量均在 [−1e−10, 1e−6]，且下述固定点残差达标 |
| 固定点残差 | 在白化参数下再计算一次 E/M 映射（不另作候选训练）；权重、均值、协方差各块的 max-absolute 差 / max(1, 该块 max-absolute 值) 均≤1e−4 |
| 似然异常 | 单次增量<−1e−10、NaN/Inf、责任度和不正确等为数值错误，暂停诊断，不能伪装成正常回退 |
| 重启选择 | 从收敛且满足第 6 节支撑门槛的重启中，选训练平均 log likelihood 最高者；差≤1e−10 取较小重启编号 |
| 空成分 | Nk=0 或播种所需平方距离总和为零：该重启无效；不得补点、换票数或随机重置到额外位置 |

固定点残差复核也计入资源消耗。200 次内未同时满足收敛与残差要求，标记 `NOT_CONVERGED`，不直接接受最后一次参数。极小负增量只按上述浮点容差记录，不宣称严格单调证明。

种子由 SHA256(`s5_e2_v1`, role, ID, origin_source_obs, horizon, K, restart, task) 的前 128 bit little-endian 生成 PCG64 状态；种子输入编码采用固定 JSON 数组 UTF-8、无空格。保存库版本。输出按白化均值字典序、协方差条目及原组件编号稳定排序，避免标签交换改变数值积分键；置换不改变分布。

## 6. 独立 drifter 支撑、回退与防过拟合

对最终责任度，定义 donor ID d 对组件 k 的责任质量 R_dk=sum_(r属于d) r_rk，以及

\[
D_{eff,k}=\frac{N_k^2}{\sum_d R_{dk}^2}.
\]

每个组件必须同时满足：

- 概率 pi_k≥0.02；责任总量 Nk≥50 条配对等价票数。
- D_eff,k≥3；至少 3 个不同 ID 各自贡献 R_dk/Nk≥0.01。
- 任一 ID 对该组件的责任占比≤0.50。
- 映回 km 坐标的 Sigma_k 条件数≤1e12。超过时该重启标记 `ILL_CONDITIONED_COMPONENT`，不抬高下限或裁剪最大特征值。若白化空间本已满足下限，映回却出现非正/非有限矩阵，应按算术错误暂停，不能掩盖为正常支撑回退。

这些仅是组件资格诊断，**不改变配对训练权重**。有效 ID 数是集中度指标，不证明独立海洋实现。另报告配对责任有效数 Nk²/sum_r r_rk²、最大 ID 占比、协方差下限触发频率、各重启似然和迭代数，不把重复小时记录当作独立重复实验。

| 情形 | 预定处理 |
|---|---|
| 至少一次重启合格 | 使用第 5 节规则选出的完整 K 成分分布 |
| 5 次均不收敛、不满足组件资格或超过组件条件数上限 | 此查询整体退回同 donor 集的 G1，标记具体原因；K=3 不另搜 K=2 |
| G1 本身不合法 / 数据或数值实现错误 | 暂停，报告；不切换 ExactPoint 或删查询 |
| 资源不足、worker 失败、文件损坏 | 暂停，不能当作模型回退 |
| 外层模型回退率>5% | 全部查询仍进入结果；不满足推广验收，不能隐去这些记录或临时减小 K |

内层每窗口的 **drifter 等权查询回退率≤5%** 才有资格进入 K 选择。报告原始查询回退比例、drifter 等权比例、涉及 ID 数及原因；“涉及某次回退的 ID 比例”与查询回退率分开。C 的 error 点质量回退另列，不能与 GMM 整条预测回退混淆。

回退不删除那条稀有落点：它仍在 G1 中拥有完整的一票。完整实现实际检验的是“受约束、支撑受控、允许退回单高斯的局部 GMM”，不得报告为所有位置均成功拟合多峰。

防过拟合的层次为：限制 K；固定协方差约束；避免单 ID 支撑一个组件；多个固定初始化减少局部解偶然性；整条 ID 与时间隔离的验证；接近时选简单模型；外层不调参。这些降低风险，**不能保证完全没有过拟合**。本轮不增加删点、去重、重新加权、交叉拟合每条训练记录或另一轮正则化搜索。

## 7. 训练期成分选择：完整、固定、可复核

### 7.1 内层评分与重复 ID

在 C_T0、C_T1 的全部 86,373 个查询上，用各自训练池拟合 G1、G2、G3。每个候选都包含第 6 节回退规则；不能只对成功拟合者算分。除已登记的 128 个工程试跑白名单查询外，先冻结每个候选所有查询的 donor、参数、回退和数值键，再开启该角色的完整验证终点评分。试跑目标只用于工程精度检查，不能进入拟合或提前选择 K。

每窗口先对 drifter 内查询取平均，再对 ID 等权。跨窗口选择分数为：先对同 ID 在每个窗口的平均分再平均，再对两个窗口 ID 的并集等权：

\[
\bar S_K=\frac1{|D|}\sum_{d\in D}\frac1{|F_d|}\sum_{f\in F_d}\frac1{n_{df}}\sum_{t\in(d,f)}ES_{K,dft}.
\]

因此同一 ID 不因横跨两个验证窗口而得到双票。窗口级分数也必须完整报告。此跨窗口汇总仅用于内部选择；外层保持原 45 ID 等权公式。

### 7.2 唯一的选择算法

1. 所有数值与源数据检查先通过。K=1 始终为基准候选；G2/G3 须满足两个窗口各自回退率≤5%。
2. 对 K>1，要求两个内层窗口 ES 点估计均不高于 G1，且上述跨窗口平均 ES 比 G1 至少降低 0.1%。方向须达到第 9 节数值分辨率，否则不具备晋级资格。
3. 在合格候选中找跨窗口 ES 最小者 b；数值等价时取较小 K。
4. 对每个合格 K 与 b 的**逐 ID 配对差**，固定种子 20261110，重抽 ID 并保留其两个窗口的所有平均分，共 10,000 次。计算配对平均差的 bootstrap 标准差 SE(K−b)。
5. 从满足 S_K−S_b≤SE(K−b) 的候选中取最小 K。这是预先定义的保守“一倍标准误”复杂度选择规则，不是经过选择后的显著性检验。若 G1 在此范围内，选 G1。
6. 若暂选 K>1，仅对它和 G1 在**两个完整内层窗口**构造统一区域并计算 H90、面积、陆地/域外质量。每窗口须 H90 不下降、平均面积不增大，且新增陆地/域外质量各≤0.01；近零差异但数值无法确认者记为未通过。
7. 第 6 步未通过则 K*=1；通过则 K* 为暂选值。**不再尝试另一个 K 来寻找通过区域门槛的结果。** K*=1 的同分布比较按恒等处理。

第 6 步的区域仅由训练产生的冻结分布构造，函数不接收真实验证终点。尽管 ES 阶段已读取内层目标，区域不得以命中情况选择中心、尺度或积分 packet。全部候选的参数与选择顺序在读取目标前冻结并有哈希。

不使用外层 ES、命中率、面积选 K、alpha、初始化、支撑阈值、积分精度或回退规则。只在训练期确定一个 K*；不按位置、年份或图像效果重新选。K>3、不同协方差结构、不同下限均不在本轮搜索空间内。

### 7.3 外层一次验证

冻结 K* 和全部规则后，在 2001–2019 年完整训练池重新对外层 33,971 个真实起点拟合。冻结全部四组分布、参数、donor、有序权重、回退、主要区域 packet 与数值键，随后开启外层目标用于新一轮评分。

若 K*=1，G* 与 G1 明确为同一个模型，不重复拟合或伪造两组独立结果；仍保留同一完整外层 roster 的 A/C/G1 对照表，结论是“内层没有支持增加成分”。相同哈希的既有参数可引用，评分须满足 E2 统一数值复核。不得因为 K*=1 就把未入选 G2/G3 的外层结果再计算出来挑选赢家。

## 8. 统一评估：ES、90% 椭圆和实际命中率

主评分与 E1 完全相同。psi 为零高程 WGS84 ECEF，单位 km，Y、Y' 独立来自完整预测分布：

\[
ES(F,y)=E\|\psi(Y)-\psi(y)\|-\tfrac12E\|\psi(Y)-\psi(Y')\|.
\]

不改用平面距离、测地距离、平方误差、Brier 或连续对数得分作为公共主评分。训练似然可以诊断拟合，不可与没有普通连续密度的 ExactPoint 作似然排名。

外层每项指标 L 的汇总均为

\[
\bar L=\frac1{45}\sum_{d=1}^{45}\frac1{n_d}\sum_t L_{dt}.
\]

保持 LAEA 中心 (lon=−75°, lat=35°)、单位 km。对各自完整预测的 LAEA 坐标 U，求均值 m、协方差 S 和自身分布的分位数：

\[
q_{.9}=\inf\{q:P_F[(U-m)^TS^{-1}(U-m)\le q]\ge.90\},
\quad R_{.9}=\{u:(u-m)^TS^{-1}(u-m)\le q_{.9}\}.
\]

面积为 pi*q_.9*sqrt(det(S)) km²；实际命中用原始精确验证坐标是否在此椭圆内判断。保留 ExactPoint 的真实原子/并列越过 90% 情况及 E8 修正后的 CDF 算法。GMM 的 q_.9 不能直接用 chi-square(2) 的分位数，也不能对各组件各画一个 90% 椭圆再取并集。

**一个椭圆可能覆盖多个峰之间的低密度空间。** 本轮有意保持该公共规则以维持可比性；GMM 学到多成分，不意味着该面积一定变小。多峰密度图仅为解释，不能拿它的 HDR 面积替代主表面积。真正退化的区域沿用 E8 几何处理，但不能用于宣称面积优势。

陆地、域外和远尾概率全部保留并报告；不裁剪、拒绝抽样、归一化到海洋、把域外当 observed first-exit E 或把陆地当搁浅。重新核对既有无 observed-E cohort；遇到退出状态不一致先暂停，不给 E 编造坐标。

辅助诊断保留 ES/(100 km)+||Epsi(Y)−psi(y)||²/(100 km)²；平方均值项使用两份独立均值估计以免模拟偏差，不参与 K 选择或验收。0.5° cell 仅用于概率展示。

## 9. 数值精度、计算复用与独立复核

### 9.1 混合 ES：完整组件求和

直接按混合权重展开期望，避免小权重组件在有限模拟中消失：

\[
ES=\sum_k\pi_k E\|\psi(Y_k)-\psi(y)\|
-\tfrac12\sum_{k,l}\pi_k\pi_l E\|\psi(Y_k)-\psi(Y_l')\|.
\]

每个积分节点生成四个独立标准正态坐标组成 Z、Z'；对所有组件分别构造 Y_k=G_x(mu_k+L_k Z)、Y_l'=G_x(mu_l+L_l Z')。必须包含 k=l 的项，且其中两次抽样仍独立。共享 Z 不改变各项期望；估计方差必须基于整个加权表达式，不能错误地把 K² 项视作独立。

- 8 个独立 scrambled Sobol replicate，四维，沿用未截尾 Box–Muller；每 replicate 1,024 / 2,048 / 4,096 / 8,192 点，对应 N=8,192 / 16,384 / 32,768 / 65,536。
- N 是**每个组件及组件对**的总节点数；不是把 N 分给 K 个组件。代价约为 2KN 个地理映射、K²N 个距离项，不能按单高斯耗时直接估计。
- G1/G2/G3 同查询共享基础积分流以减少差值误差；公共数值种子不包含 K，包含 role、查询、task、replicate、E2 版本。EM 种子仍包含 K。复核使用不同 namespace。
- A/C 复用已验证的成对 ES 算法、完整 CI-minus-point 增量及独立 1,024 样本控制变量校准；组件等票数不变，与 G 系列积分流独立。总配对抽样层级同为 N。不能把旧展示值当成没有误差的常数直接相减。
- 通过 8 个 replicate 的**完整配对差**估计数值方差；查询间独立积分流，以评估权重平方汇总数值方差。不把 Sobol 节点当作 IID 记录。

### 9.2 区域积分

GMM 每组件使用 M=32,768 或 65,536 个二维 Sobol 正态节点，节点权重 pi_k/M；以全部带权节点算 LAEA 矩和带权 Mahalanobis 分位数。每个 reconstruction packet 都有完整 M 点/组件，不能因 K 增加而减少组件样本。

replicate 0 是唯一报告区域；replicate 1 独立重建。另从完整混合分布 IID 抽 M 个点检查主要区域、陆地与域外质量；该 checker 的 M 为整个分布总量，组件按 pi 真实抽取。C 沿用原分层核积分，A 精确枚举全部 donor。不得将 Sobol 检查结果套用二项 Wilson 区间。

### 9.3 精度门槛

沿用 E1 数值要求，扩展到所有用于选择或正式判断的配对差：

1. donor/roster/权重身份一致；概率和误差≤1e−10；原始终点地理往返误差≤1e−6 km。
2. 聚合 ES 差的 3 个估计数值标准误≤基准 ES 的 0.0001；独立重复差异还须≤所声称 ES 改善的 10%。用于内层晋级的近零变化无法分辨时不晋级。
3. IID 区域 checker 给每查询 Wilson 95% 区间，半宽 h 取至两端较大值，h≤0.005。设 b 为既有真实边界原子质量，要求加权平均 distance(p_hat,[.90,.90+b])+h≤0.005。G1/GMM 的 b=0；数值节点并列不算概率原子。报告个别 outlier；此规则不是逐查询同时置信保证。
4. 独立区域重建的加权命中判定分歧≤0.001，平均面积相对变化≤0.005。对声称的非零命中/面积改善，数值不确定性须≤改善幅度的 10%；否则方向不明确。恒等模型直接按相等处理。
5. 陆地、域外质量各自聚合数值不确定性≤0.001；接近质量门槛且误差足以逆转判断时，不得宣称通过。

128 个预定试跑查询：每内层窗口按稳定源键排序，索引 floor(j*(N_role−1)/63)，j=0…63。每查询使用完整训练池和完整 donor；A/C、所有 K、5 重启、必要精度层级均纳入。试跑只检查实现、精度与成本，不提前选择 K 或报告完整窗口预测结论。仅开放这些固定内层目标，不开放其他内层或外层目标来辅助试跑。

按精度选最小共同 N/M，冻结后正式运行。M=32,768 与 65,536 对比；最高层仍须通过独立 65,536 重建。没有自动增加到 131,072 的权限。试跑汇总按其出现的 ID 等权；全量数值误差投影采用试跑最大逐查询对比方差乘完整角色 sum(w²)，并说明不是对未知查询的严格上界。全量实际精度仍须逐项复核。

基本精度门槛不过关，或试跑无法在预算内检查完毕：暂停报告，不降低精度、减少样本或临时换估计器。基本精度已经通过、但某个微小效应达不到“误差≤改善的 10%”时，内层不晋级，外层将相应方向或门槛标为不确定；不因此追加积分层级或继续调参。判定为统计无改善/不确定与判定为工程未完成必须区分。

### 9.4 独立复核范围

- 全量内层和外层重新核对角色、配对、donor 哈希和未改动的等权票数；所有冻结参数独立重算 log likelihood、责任度、约束、支撑量、固定点残差、回退逻辑。
- 全量外层对所有独特分布另用独立数值流复算 ES、90% 区域与逐 ID 汇总；重复别名 G*=G1 只算一次。
- 固定 128 个外层审计键为排序后 floor(j*(33971−1)/127)，j=0…127。用独立数组运算路径重建完整 donor、重做所选 K 的 5 重启；用独立 IID 65,536 对模拟验证地理 ES，不主张找到了全局最优似然。
- 全量内层候选 ES 使用自身 8 replicate 精度检查，并独立重算所有逐 ID 汇总与唯一选择路径；内层暂选候选和 G1 的区域完成双 packet / IID 检查。抽取同一固定 128 内层键作独立拟合复核。不得将子集复核称作全量独立重训。
- 所有来源及历史保护文件哈希一致，未读取 final-test；记录并区分统计不确定性与数值误差。

## 10. 统计分析及验收标准

外层 45 个 ID 为重抽单位，10,000 次配对 bootstrap，种子 20261111；每次保留该 ID 的完整查询平均分以及全部模型配对。报告 ES 差、H90 差、平均面积比的 percentile 双侧 95% 区间。固定预测、不重新训练的区间不含参数重新拟合不确定性，也不消除共同海洋强迫造成的相关性。

主要比较为 G*−G1；必须同时完整报告 G*−A、G*−C。支持优越性的判断固定依次为 G1 → A → C，前一项未通过不宣称后一项建立了整体胜出。所有对比照常展示，不能挑最有利的基准。

| 验收层次 | 必须满足 |
|---|---|
| 工程完成 | 全部 86,373 内层查询及 33,971 外层查询完整保留；源数据、角色、拟合、概率、数值与独立复核通过；无未解释异常 |
| 支持增加成分 | K*>1；内层固定选择路径通过；外层 G*−G1 达到下列有用 ES 改善及质量门槛 |
| 对某基准有用的 ES 改善 | 均值相对降低≥0.1%，配对 ES 差 95% 区间上界<0，数值误差已分辨 |
| 观察到的质量不退化 | G* 的 H90≥基准，平均面积≤基准；不能把点估计下降包装为“没有显著差异所以不退化” |
| 统计不确定性门槛 | H90 差 95% 区间下界≥−0.01；平均面积比区间上界≤1.02 |
| 地理质量门槛 | 新增平均陆地质量≤0.01，新增域外质量≤0.01，分别通过且数值可分辨 |
| 模型回退门槛 | 外层 drifter 等权查询回退率≤5%；全部回退记录仍参与主评分 |
| 可讨论作为更好模型 | 对 G1、A、C **全部**达到有用 ES 改善及质量/地理门槛，无真正退化区域带来的虚假面积优势 |

1 个百分点与 2% 是统计区间容许范围，不是允许点估计退化的“优惠”。实际命中下降或面积增大，即便 ES 改善，也应报告为 trade-off。命中增加但面积同时增大，不自动称为总体改善。

描述性附表包括年份、donor 支撑量、最大 ID 占比、组件支撑、下限触发、回退、逐 ID ES 和 leave-one-ID-out 敏感性，不用事后分组替代主结果。

完成的无改善/不确定结果也是有效研究证据。K*=1 表示本轮内层没有足够理由增加成分，不等于证明海洋落点单峰；选到 K>1 也不等于证明存在 K 个物理峰。若只优于 G1、仍不如 A/C，则结论为“修复了一部分高斯近似损失”，不能宣称已经超过经验预测。
