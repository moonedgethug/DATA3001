## 结论

- 383 个 ID 全部找到唯一的官方目录行；完整 ID、WMO、首次有效日期和起点坐标均核对通过。四份目录的完整文件 SHA256 与项目 2026-10-16 保存的来源相同。

- 对同一组 383 个 ID 的历史 571,823 条合格七天／三十天配对进一步核查，**所需观测区间结束超过官方结束时刻：0 条**。同一个一分钟起点分别形成七天和三十天各一条配对。
- 保留上轮确认的 12 条配对。当前没有因“终点使用了官方结束后的记录”而重训现有模型的依据。分钟级起点是否应排除尚未确证，不自行删样本。
- 本轮结论只覆盖这 383 个 ID，不能外推为整个历史开发池或封存 final-test 均已检查。

建议：对这 87 条建立审计警示，未来扩大起点区域、时长或重新建配对时必须重新审查；本轮不删除原记录，也不重跑现有模型。这里只确认时间范围冲突，未证明其物理位置错误或具体发生原因。

## 5. 处理建议与停止边界

1. **保留上轮 12 条配对及当前冻结数据。** 不将原生零点 end_date 当作分钟级硬边界直接删记录。
2. **363 个纯精度差异 ID 与 11 个结束元数据后来补全的 ID，到审计登记为止。** 当前没有需要重新训练的配对变化。
3. **62228 的 87 条及五个来源冲突 ID 的相关尾段保留独立警示。** 它们没有进入现有合格配对，故不触发模型重跑。未来重建输入时必须重新经过资格核查。
4. **75447 的一分钟起点暂保留并标注。** 最短后续路径是核实小时产品在首末边缘的生成/保留规则；不因看到一分钟差异立即大规模重训。若无法获得更强来源，而研究决定新增“严格分钟边界”政策，再预先批准仅排除该起点配对的敏感性方案、原选择规则和预算。
5. **不因本次审计撤销已有季节、精确位置或高斯结果，也不把它们称为已证明完全不受边界处理影响。** 若将来改变一分钟记录的资格，才需按保存依赖局部重拟合并复核参数选择；保留所有旧结果作版本对照。

未解决项明确为：五个 ID 的源版本结束信息冲突，以及三个分钟级小时网格边缘的资格解释。其中只有 75447 的边缘记录进入已用研究配对。审计完成不等于这些问题已被数据修复解决。
